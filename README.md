# Depbot

A browser warehouse puzzle in which a stacker carries crates, stores them and fills orders.

[Depbot at Burrito’s Labs](https://burritoslabs.com/?preview=depbot#upcoming-games)

## Technology

JavaScript modules and browser rendering with keyboard and pointer controls.

## Architecture

The warehouse rules track crate locations, rack space and order fulfillment. Layout and earlier storage decisions affect later journeys through the warehouse.

## Product behavior

The studio preview shows the playable movement and crate-handling loop.
